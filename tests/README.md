
# 2DGame 自動テスト

このディレクトリには、ゲームの各システムの動作を保証するための自動テストスクリプトが含まれています。
デグレ（機能退行）を防ぐため、重要なロジックを変更した際はこれらのテストを実行してください。

## テストの実行方法

プロジェクトルートディレクトリから以下のコマンドを実行してください：

```bash
./venv/bin/python tests/test_hitbox.py
```

## 含まれているテスト

### 1. `test_hitbox.py`
- **当たり判定テスト**: プレイヤーの攻撃が正しい範囲に届くかを確認します。
- **巨大敵対応テスト**: 2x2タイルなどの大型モンスターに対して、見た目通りの範囲で攻撃が当たるかを確認します。
- **武器射程テスト**: 片手剣（1マス）や槍（2マス）など、武器ごとの攻撃範囲が正しく機能するかを確認します。
