# 2DGame 自動テスト群 (Regression Tests)

このディレクトリには、ゲームの各システムの動作を保証し、**デグレ（機能退行）**を防ぐための自動テストスクリプトが含まれています。
ゲームのコアロジックや当たり判定、UI、セーブデータ構造などを変更した際は、必ずこれらのテストを実行して既存機能が壊れていないか確認してください。

## テストの実行方法

プロジェクトルートディレクトリから以下のコマンドを実行してください：
（例）
```bash
./venv/bin/python tests/test_hitbox.py
```
一括実行（Bashの場合）:
```bash
for test in tests/test_*.py; do ./venv/bin/python "$test"; done
```

## 含まれているテストケース一覧

### 1. 描画・初期化
- **`test_boot.py`**
  - **テストケース**: ゲームのメインループが正常に起動し、1フレームの更新（update）および描画（draw）フェーズをエラーなく完了できるか。
  - **期待値**: `NameError` や `TypeError` などのクラッシュが発生せず、正常に描画バッファが生成されること（Exit code 0）。

### 2. 当たり判定・衝突・移動系
- **`test_hitbox.py`**
  - **テストケース**: プレイヤーの攻撃が正しい範囲に届くか。巨大敵（2x2タイル等）に対して見た目通りの範囲で攻撃が当たるか。武器種（片手剣の1マス、槍の2マス貫通など）の射程が機能するか。
  - **期待値**: 攻撃対象のグリッドに敵が存在する場合にのみヒット判定が返ること。
- **`test_enemy_collision.py`**
  - **テストケース**: 敵同士、および敵とプレイヤーが同じマスに重ならない（オーバーラップしない）ように移動制御が機能するか。
  - **期待値**: 移動先の `get_occupied_grids()` を参照し、すでに他エンティティがいる場合は移動がキャンセルされること。
- **`test_collision_phasing.py`**
  - **テストケース**: 移動中のエンティティが「現在地」だけでなく「目標地点（target_x, y）」も占有マスとして正しく報告し、すり抜け（Phasing）が発生しないか。
  - **期待値**: すれ違いざまの移動入力に対して、両者がブロックし合い、重なることなく元のマスに留まること。
- **`test_npc_collision.py`**
  - **テストケース**: 村に配置されたNPCが障害物として認識され、プレイヤーがNPCのマスに侵入できないか。
  - **期待値**: NPC座標に対する移動入力がブロックされること。

### 3. 戦闘・ステータス系
- **`test_combat_logic.py`**
  - **テストケース**: 攻撃アクション時に、エンティティの基本攻撃力・武器の補正値・乱数などが正しく加味され、ダメージ計算が適正に行われるか。
  - **期待値**: 防御力0の相手に対し、`(攻撃力 - 防御力) * 乱数` の範囲内のダメージが計算され、対象のHPが減少すること。
- **`test_combat_sim.py`**
  - **テストケース**: 連続してターンを進行させた際、攻撃のクールダウンや状態異常（毒など）が正しくターン経過とともに消費されるか。
  - **期待値**: 指定ターン経過後にHPが想定通り減少し、ステータス異常が解除されること。

### 4. ダンジョン進行・セーブ・ゲームフロー
- **`test_game_flow.py`**
  - **テストケース**: 階段の上り下り、村からダンジョンへの遷移など、`warp_to_floor` を経由したマップ生成フローがエラーなく完了するか。
  - **期待値**: ダンジョンインスタンスが正しく切り替わり、`current_floor` が期待する階層に一致すること。
- **`test_rank_up_entrance.py`**
  - **テストケース**: プレイヤーのギルドランク（C, B, Aなど）に応じて、ダンジョンへの入場制限や適切な難易度の階層が生成されるか。
  - **期待値**: 規定のランクに達していない場合に入場が拒否される、もしくは特定のフラグが立つこと。
- **`test_death.py`**
  - **テストケース**: プレイヤーのHPが0になった際、死亡演出がトリガーされ、所持品のロスト計算と村への強制送還（0階へのワープ）が実行されるか。
  - **期待値**: HP0時に `is_death` フラグが立ち、ペナルティ適用後の状態でセーブデータが上書きされること。
- **`test_save_load.py`**
  - **テストケース**: 装備品（インスタンスIDや特殊効果）や所持品、プレイヤーのステータスがファイルに書き出され、再起動時に完全に復元できるか。
  - **期待値**: ロード後のプレイヤーオブジェクトの `__dict__`（属性）がセーブ前と完全に一致すること。

### 5. UI・NPCサービス系
- **`test_shopping.py`**
  - **テストケース**: 商店でのアイテム購入および売却において、プレイヤーの所持金（コイン）の増減とインベントリへのアイテム移動が正しく行われるか。
  - **期待値**: 購入額が手持ちコインから引かれ、インベントリの空き枠に指定アイテムが追加されること。
- **`test_blacksmith.py`**
  - **テストケース**: 鍛冶屋での装備強化（エンハンス）ロジックが機能し、鉱石（Ore）を消費して装備の `enhance` 値と `attack_bonus` などが上昇するか。
  - **期待値**: 指定された素材数が減少し、対象装備のパラメータが+1以上されること。
- **`test_quest.py`**
  - **テストケース**: ギルドクエストの受注、進行度カウント（討伐数や収集数）、および達成時の報酬付与とランクポイント加算が機能するか。
  - **期待値**: クエスト条件を満たした状態で報告した際、ステータスに経験値・報酬が反映され、クエストリストからクリア済みとして処理されること。
