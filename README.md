## 座標系について (Coordinate System)

このゲームで使用している座標系（特に `hand_offsets` など）のルールを説明します。

### 1. 座標の原点
座標の原点 `(0, 0)` は、**「画像（スプライト）の左上角」** です。

### 2. Y軸の向き (重要!)
Pygame の座標系では、**下に行くほど Y 座標の値が大きく** なります。
- `Y = 0`: 画像の最上部（頭のてっぺん）
- `Y = 64`: 画像の最下部（プレイヤーの足元。プレイヤーは 64x64 です）
- **マイナスの値 (例: -20)**: キャラクターの頭上（画像の外）に突き抜けます。

### 3. 設定値の例 (`constants.py`)
武器の持ち手位置などを調整する場合：
- **X を増やす**: 右へ移動
- **X を減らす**: 左へ移動
- **Y を増やす**: **下**へ移動（足元に近づく）
- **Y を減らす**: **上**へ移動（頭に近づく）

## 武器データの構造 (Weapon Data Structure)

武器の設定は `constants.py` で管理されており、「武器種」と「個別データ」の2段階に分かれています。

### 1. WEAPON_TYPES (共通設定)
`OneHanded` や `Bow` といった武器の種類ごとに、アニメーションや描画のルールを定義します。
- **hand_offsets**: 手の位置。
- **weapon_angles**: 武器の回転角度。
- **draw_over_player**: プレイヤーの前に描画するか後ろか。

### 2. WEAPON_DATA (個別データ)
実際の武器（例：鉄の剣、木の棒）のステータスを定義します。
- **type**: `WEAPON_TYPES` のどの設定を使うか指定します。
- **image_path**: 画像ファイルのパス。
- **attack_bonus**: 攻撃力の加算値。

## ダンジョンタイルの仕様 (Dungeon Tile Specification)

壁のオートタイル（自動連結）で使用する画像のルールを説明します。

### 1. 壁のコーナー画像 (`wall_corner.png`)
プログラム側で自動的に反転（Flip）させて4隅に対応させるため、基本となる画像は**「（床から見て）左上の角」**に合わせて作成してください。

*   **基本画像 (`wall_corner.png`)**: 「右」と「下」に床がある場所（＝部屋の**左上角**の壁）
*   **左右反転 (Flip X)**: 「左」と「下」に床がある場所（＝部屋の**右上角**の壁）
*   **上下反転 (Flip Y)**: 「右」と「上」に床がある場所（＝部屋の**左下角**の壁）
*   **上下左右反転 (Flip X & Y)**: 「左」と「上」に床がある場所（＝部屋の**右下角**の壁）
