# 🗡️ 2D Rogue-like RPG project

Pygameベースで開発されている、本格的なローグライクRPGプロジェクトです。
自動生成されるダンジョン、装備の成長、ギルドランクシステムなど、拡張性と遊びごたえを両立した設計を目指しています。

---

## 🎮 操作方法 (Controls)

| キー | アクション |
| :--- | :--- |
| **矢印キー** | 移動 / カーソル操作 |
| **Z / Enter** | 決定 / 攻撃 / 調べる |
| **X / Esc** | キャンセル / メニュー開閉 |
| **Shift + 矢印** | その場での方向転換 |

## 🏗️ プロジェクト構造 (Architecture)

### 1. マスターデータ (`components/data/master/`)
ゲームのバランス設定はすべて YAML ファイルで管理されており、コードを修正せずに調整が可能です。
- **`weapons.yml` / `armors.yml` / `shields.yml`**: 装備品データ
- **`items.yml`**: 消費アイテム、杖、カンテラの設定
- **`enemies.yml`**: 敵のステータス、行動パターン、出現階層
- **`balance.yml`**: 経験値テーブル、ランクアップ条件、階層ごとの難易度定数

### 2. システムコア (`systems/`)
- **`dungeon.py`**: マップ生成ロジック、階層遷移
- **`combat.py`**: ダメージ計算、命中判定
- **`ui.py`**: ダイアログ、ショップ、メニュー描画
- **`death_handler.py`**: 死亡ペナルティ、復活処理

## 🧪 開発・テスト環境 (Testing)

### 自動テストの実行
本プロジェクトでは、デグレ（先祖返り）を防ぐために包括的なテストスイートを備えています。
```bash
./run_tests.sh
```

### 🛡️ セーブデータ保護機構
テスト実行時は環境変数 `TEST_MODE=1` が自動的にセットされ、本番用セーブデータ（`save_official.json`）を汚染しないよう、テスト用ファイル（`save_data_test.json`）へリダイレクトされます。`run_tests.sh` は開始時にこの隔離が正しく機能しているかを自動検証します。

## 🛠️ 技術仕様 (Technical Specs)

### 座標系
- 原点 `(0, 0)` は画像の左上角。
- Y軸は **下に行くほど正の値**。
- タイルサイズは標準 **64x64** ピクセル。

### 壁のオートタイル
`wall_corner.png` は「部屋の左上角」を基準に作成してください。プログラムが動的に反転（Flip）させて4隅に対応させます。
