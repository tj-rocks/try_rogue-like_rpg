# 🛠 デバッグ・テストガイド

このドキュメントでは、新しく実装されたギルドシステムやエンディング機能を効率的にテストするためのデバッグツールの使い方を説明します。

## 1. デバッグツールの起動
以下のコマンドで、テスト専用の環境を起動できます。
```bash
python tools/debug_guild_quest.py
```
※このツールではプレイヤーが「無敵」になり、ギルド職員の目の前からスタートします。

## 2. デバッグ操作（キーボードショートカット）
ツール実行中に以下のキーを押すことで、状態を即座に変更できます。

| キー | アクション | 用途 |
| :--- | :--- | :--- |
| **`R`** | ギルドランク切替 | F -> E -> D... とランクを順番に変更します。 |
| **`G`** | GP追加 (+100) | 昇格条件を満たすためにGPを増やします。 |
| **`W`** | 主要階層ワープ | 0, 13, 25, 38, 50, 63, 75, 88, 99階をサイクル移動します。 |
| **`K`** | 父の遺品を入手 | 即座に最終アイテムを取得し、エンディングのテストができます。 |
| **`SPACE`** | 決定 / 攻撃 | ギルド職員への会話や、証の取得に使用します。 |
| **`X`** | キャンセル / 閉じる | ダイアログを閉じます。 |

---

## 3. テストの基本パターン

### 昇格試験のテスト
1. `R` を押して、現在のランクを調整する（例：Fランク）。
2. `G` を数回押し、昇格に必要なGPを貯める。
3. ギルド職員に話し掛け、出現した「昇格依頼」を受注する。
4. **`W` を押し、ターゲット階層（例：13階）へワープ**する。
5. 部屋のどこかに落ちている「ギルド証」を拾う。
6. **`W` を数回押し、0階（村）へ戻る**。
7. ギルド職員に報告し、ランクが上がることを確認する。

### エンディングのテスト
1. **`K` を押し、「父の遺品」を強制取得**する。
2. **`W` を数回押し、0階（村）へ戻る**。
3. 村に入った瞬間にエンディング（紙芝居）が流れることを確認する。
4. エンディング終了後、そのままゲームが続行できることを確認する。
5. 再度村に入ってもエンディングが流れない（1回きり）ことを確認する。

---

## 4. 注意事項
- このツールは `tools/` フォルダ内にあるスクリプトでのみ有効です。
- 通常の `main.py` から起動した場合は、これらのデバッグキーは機能しません（本番環境のバランスを壊さないため）。
