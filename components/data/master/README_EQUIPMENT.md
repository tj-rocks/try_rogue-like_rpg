# 装備品パラメータ定義ガイド

このドキュメントは、`equipment.yml` で使用されている各パラメータの意味を解説します。

## 共通パラメータ

| パラメータ | 意味 | 補足 |
| :--- | :--- | :--- |
| `name` | 画面表示名 | 日本語で指定 |
| `category` | 分類 | `heavy`, `medium`, `light`, `robe` など |
| `min_rank` | 装備制限ランク | F 〜 SS |
| `rarity` | 希少度 | 1〜5 |
| `price` | 基本価格 | 売却時はこの 1/2 になる |
| `shop_buyable` | 店頭販売 | `true` でショップに並ぶ |
| `describe` | 説明文 | 装備詳細画面で表示される |

## ステータス補正

| パラメータ | 意味 | 計算式への影響 |
| :--- | :--- | :--- |
| `defense_bonus` | 防御力 | 被ダメージを割合カットで軽減する（ダメージ計算式参照） |
| `hp_bonus` | HP増減 | 最大HPに加算される |
| `regen_bonus` | **自然回復ブースト** | 基本は自然回復なし。ボーナス1につき 0.01 加算（+10で10ターンにつき1回復） |
| `eva_bonus` | 回避率 | 整数指定 (15 = 15%) |
| `crit_bonus` | 会心率 | 実数指定 (0.05 = 5%) |
| `aggro_mod` | 感知補正 | 数値が大きいほど敵に狙われやすい（実験的） |

## 成長の限界 (growth)

装備を鍛冶屋で強化（色石によるパラメータ個別強化）した際の成長特性を定義します。

現行は **固定上限＋減衰カーブ方式** です。ベース値に関係なく、`times_limit` 回で一律 **+10（整数系ステータス）** または **+10%（%系ステータス: `armor_penetration` / `block_chance_close` / `block_chance_ranged` / `crit_bonus`）** まで成長します。

| パラメータ | 意味 | デフォルト値 |
| :--- | :--- | :--- |
| `bonus_limit` | （現在未使用。上限は固定値+10/+10%で計算されるため無視されます） | 2 |
| `times_limit` | 上限（+10 / +10%）に到達するまでの強化回数 | **30** |
| `over_limit_growth_rate` | 上限到達後の1回あたり成長率（`growth_room × この値`） | 0.003 |

### 減衰カーブ（`times_limit: 30` の場合）
最初に大きく上がり、後半は微増します（`growth_room` = +10 または +10%）。

- 1〜10回目: `growth_room × 0.5` まで（1回あたり +5%相当）
- 11〜20回目: `growth_room × 0.8` まで（1回あたり +3%相当）
- 21〜30回目: `growth_room × 1.0`（上限）まで（1回あたり +2%相当）
- 31回目以降: 上限 + `(回数 - times_limit) × growth_room × over_limit_growth_rate`（微増）

※ 例: 攻撃力ステータス（整数系・`growth_room=10`）を強化した場合、30回で +10 に到達し、31回目以降は1回ごとに約 +0.03 ずつ微増します。

> ⚠ `times_limit` はコードの減衰カーブのブレークポイント（10 / 20 / 30）に合わせて **30** を前提としています。これ以外の値（例: 50）にすると、上限到達回数付近で成長量が不連続になります。

## ⚔️ 戦闘ダメージ計算式

物理攻撃による基本ダメージは、単純な引き算ではなく、インフレに強い**割合軽減（除算）方式**を採用しています。

$$\text{基本ダメージ} = \text{攻撃力} \times \left( \frac{50}{50 + \text{防御力}} \right)$$

### 🛡️ 防御力ごとのダメージカット率（軽減率）の例
- **防御力 0** : 軽減なし (100% ダメージが通る)
- **防御力 25** : 33.3% 軽減 (約 1/3 カット)
- **防御力 50** : 50% 軽減 (ダメージ半減)
- **防御力 100** : 66.6% 軽減 (約 2/3 カット)
- **防御力 150** : 75% 軽減 (ダメージが 1/4 になる)
- **防御力 450** : 90% 軽減 (ダメージが 1/10 になる)

この方式により、パラメータが少し強化されただけでダメージが急激に跳ね上がったり、防御力が高い敵に対してダメージが一切通らなくなったりする問題を防ぎ、マイルドで安定したハクスラバランスを実現しています。
