# 装備品パラメータ定義ガイド

このドキュメントは、`equipment.yml` で使用されている各パラメータの意味を解説します。

## 共通パラメータ

| パラメータ | 意味 | 補足 |
| :--- | :--- | :--- |
| `name` | 画面表示名 | 日本語で指定 |
| `category` | 分類 | `heavy`, `medium`, `light`, `robe` など |
| `min_rank` | 装備制限ランク | F 〜 SS |
| `rarity` | 希少度 | 1〜5 |
| `price` | 基本価格 | 売却時はこの 1/2 になる |
| `shop_buyable` | 店頭販売 | `true` でショップに並ぶ |
| `describe` | 説明文 | 装備詳細画面で表示される |

## ステータス補正

| パラメータ | 意味 | 計算式への影響 |
| :--- | :--- | :--- |
| `defense_bonus` | 防御力 | 被ダメージを割合カットで軽減する（ダメージ計算式参照） |
| `hp_bonus` | HP増減 | 最大HPに加算される |
| `regen_bonus` | **自然回復ブースト** | 基本は自然回復なし。ボーナス1につき 0.01 加算（+10で10ターンにつき1回復） |
| `eva_bonus` | 回避率 | 整数指定 (15 = 15%) |
| `crit_bonus` | 会心率 | 実数指定 (0.05 = 5%) |
| `aggro_mod` | 感知補正 | 数値が大きいほど敵に狙われやすい（実験的） |

## 成長の限界 (growth)

装備を鍛冶屋で強化した際の成長特性を定義します。未設定の場合は「強化1回につきステータス+1」となります。

| パラメータ | 意味 | デフォルト値 |
| :--- | :--- | :--- |
| `bonus_limit` | ソフトキャップ倍率 | 2.0 (ベースの2倍までが通常成長) |
| `times_limit` | キャップ到達までの回数 | 50 (50回で上記倍率に到達) |
| `over_limit_growth_rate` | 超過後の成長率 | 0.003 (ベースの0.3%/回に減衰) |

※ 例: 攻撃力10の剣で `bonus_limit: 2`, `times_limit: 50` の場合、50回目までは1回ごとに +0.2 成長し、51回目以降は1回ごとに +0.03 成長します。

## ⚔️ 戦闘ダメージ計算式

物理攻撃による基本ダメージは、単純な引き算ではなく、インフレに強い**割合軽減（除算）方式**を採用しています。

$$\text{基本ダメージ} = \text{攻撃力} \times \left( \frac{50}{50 + \text{防御力}} \right)$$

### 🛡️ 防御力ごとのダメージカット率（軽減率）の例
- **防御力 0** : 軽減なし (100% ダメージが通る)
- **防御力 25** : 33.3% 軽減 (約 1/3 カット)
- **防御力 50** : 50% 軽減 (ダメージ半減)
- **防御力 100** : 66.6% 軽減 (約 2/3 カット)
- **防御力 150** : 75% 軽減 (ダメージが 1/4 になる)
- **防御力 450** : 90% 軽減 (ダメージが 1/10 になる)

この方式により、パラメータが少し強化されただけでダメージが急激に跳ね上がったり、防御力が高い敵に対してダメージが一切通らなくなったりする問題を防ぎ、マイルドで安定したハクスラバランスを実現しています。
