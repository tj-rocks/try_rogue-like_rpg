# 装備品パラメータ定義ガイド

このドキュメントは、`equipment.yml` で使用されている各パラメータの意味を解説します。

## 共通パラメータ

| パラメータ | 意味 | 補足 |
| :--- | :--- | :--- |
| `name` | 画面表示名 | 日本語で指定 |
| `category` | 分類 | `heavy`, `medium`, `light`, `robe` など |
| `min_rank` | 装備制限ランク | F 〜 SS |
| `rarity` | 希少度 | 1〜5 |
| `price` | 基本価格 | 売却時はこの 1/2 になる |
| `shop_buyable` | 店頭販売 | `true` でショップに並ぶ |
| `describe` | 説明文 | 装備詳細画面で表示される |

## ステータス補正

| パラメータ | 意味 | 計算式への影響 |
| :--- | :--- | :--- |
| `defense_bonus` | 防御力 | 被ダメージを直接減らす |
| `hp_bonus` | HP増減 | 最大HPに加算される |
| `regen_bonus` | **自然回復ブースト** | 基本値 0.05 に加算。1.0 貯まるごとにHPが1回復 |
| `eva_bonus` | 回避率 | 整数指定 (15 = 15%) |
| `crit_bonus` | 会心率 | 実数指定 (0.05 = 5%) |
| `aggro_mod` | 感知補正 | 数値が大きいほど敵に狙われやすい（実験的） |

## 防具のボーナスグループ構造

防具（`armors.yml`）のパラメータは、可読性と設計の美しさを考慮し、以下の2つのグループ構造（ネスト構造）で定義されています。

### 1. `common_bonus` (通常ステータス補正)
防具が持つ基本的な物理的・汎用的なステータス補正です。

| パラメータ | 対応旧キー | 意味 | 補足 |
| :--- | :--- | :--- | :--- |
| `defense` | `defense_bonus` | 物理防御力 | 被ダメージを直接減らす値。 |
| `hp` | `hp_bonus` | 最大HPボーナス | 最大HPに直接加算される値。 |
| `accuracy_close` | `accuracy_bonus` | 命中補正 | 物理攻撃の命中精度に加算。 |
| `eva` | `eva_bonus` | 回避率ボーナス | 物理攻撃の回避率。 (0.05 = 5%アップ) |
| `crit` | `crit_bonus` | 会心率ボーナス | クリティカルの発生率。 (0.08 = 8%アップ) |
| `attack` | `attack_bonus` | 物理攻撃力ボーナス | 物理攻撃力に直接加算される値。 |

### 2. `magic_bonus` (魔法・杖ステータス補正)
杖（Stave）を使用する魔法攻撃や魔法効果を直接強化する特別なボーナス群です。

| パラメータ | 意味 | ゲーム内での具体的な効果・計算方法 |
| :--- | :--- | :--- |
| `stave_bonus` | 杖初期回数ボーナス | 新しく杖を拾ったり購入した際の、**杖の初期使用回数**を直接上乗せ。 (例: `3` で `5回` → `8回` へ増加) |
| `fire_damage` | 魔法追加攻撃力 | 火炎や吹き飛ばし等、**敵に魔法ダメージを与える際**の基本攻撃力に直接加算。 |
| `knockback_damage` | 吹き飛ばし距離延長 | 吹き飛ばしの杖を振った際の**最大吹き飛ばしマス数**を直接延長。（最低1マス下限保証） |
| `fire_area` | 炎ダメージ倍率加算 | 火炎の杖による範囲炎ダメージの**ダメージ倍率**に直接加算。 (例: `0.5` で `1.5倍` → `2.0倍` へ大強化) |
| `heal_bonus` | 魔法回復量加算 | 回復の杖を使用した際の**自己回復量**に、固定値を追加上乗せ。 |
| `invincible_bonus` | 無敵時間ターン延長 | 無敵の杖で付与される**「被ダメージ完全無効状態」の持続ターン数**を直接延長。 |
| `stupidity_bonus` | 敵アホ化補正 | 周囲の敵の `stupidity`（バカ度）を直接上昇させ、**ターン毎にぼーっと徘徊する確率**を上昇させる。また、アホ度合計が `7` 以上になった敵はプレイヤーを追いかける賢いAI（包囲や逃げ道封鎖など）が強制無効化され、ただ歩き回るだけのおバカ状態になる。 |

## 成長の限界 (growth)

装備を鍛冶屋で強化した際の成長特性を定義します。未設定の場合は「強化1回につきステータス+1」となります。

| パラメータ | 意味 | デフォルト値 |
| :--- | :--- | :--- |
| `bonus_limit` | ソフトキャップ倍率 | 2.0 (ベースの2倍までが通常成長) |
| `times_limit` | キャップ到達までの回数 | 50 (50回で上記倍率に到達) |
| `over_limit_growth_rate` | 超過後の成長率 | 0.003 (ベースの0.3%/回に減衰) |

※ 例: 攻撃力10の剣で `bonus_limit: 2`, `times_limit: 50` の場合、50回目までは1回ごとに +0.2 成長し、51回目以降は1回ごとに +0.03 成長します。

## Dランク以降のビルドスタイル設計方針

Dランク以降の装備品は、単なるステータス上昇に留まらず、プレイヤーが様々なビルド（プレイスタイル）を楽しめるように、特徴的な個性（リジェネ、HP補正、クリティカル率、ヘイト補正、回避率など）を付与します。

### 代表的なビルドスタイルと装備コンセプト

| ビルドタイプ | 主な装備構成 | 特徴・パラメータ調整方針 |
| :--- | :--- | :--- |
| **アンバサ戦士** | 聖剣、ローブ、聖盾 | **HP上昇・高いリジェネ**。基本の物理防御や物理攻撃は低めに抑える。 |
| **バランス戦士** | 剣、軽鎧 / 中装鎧 | **全体的なバランス重視**。極端な弱点や強みのない堅実な構成。 |
| **侍** | 刀、鎧、盾 | **クリティカル（会心率）特化**。通常攻撃力は低いが、一撃の威力を狙う。 |
| **脳筋戦士** | 斧、重鎧、重盾 | **超高防御力・高火力**。ただし、重装のため敵に気付かれやすい（ヘイト高）。 |
| **盗賊** | 短剣、軽装 / ローブ | **隠密（低ヘイト）・クリティカル依存**。最大HPにマイナスボーナス（低耐久力）。 |
| **神回避** | 盾、特殊装備 | **ブロック率特化**。攻撃を完全に受け流すことを至上命題とする。 |
| **軽業** | 剣、軽装 | **回避特化**。攻撃面はバランス型で、敵の攻撃を避けて手数を稼ぐ。 |
