# ストーリーNPC配置コンセプト（将来の配置作業向けガイドライン）

このドキュメントは、F〜SSランクまでの各休憩所マップが完成した後に、ストーリーNPCを正しく配置するためのコンセプトと仕様をまとめたものです。
AIに配置を依頼する際は、「このテキストを読んで配置して」と指示してください。

## 1. 基本コンセプト
- ストーリーNPC（ユル、カヤなど）は「現在のプレイヤーランクに対応する休憩所（村を含む）」にのみ出現する。
- ランクごとのセリフが設定されている（＝そのランクで語るべきストーリーがある）場合のみ配置する。
- 途中で死亡・引退などの理由でセリフ（ストーリー）が欠落しているランクの休憩所には、そのNPCは出現させない。

## 2. YAMLファイルでの定義・制御方法
各マップ用設定ファイル（`village.yml` や将来作成される `rest_point_A.yml` 等）の `positions` において、`min_rank` と `max_rank` を用いて出現を制御する。

### 設定例（カヤの場合）
カヤは F, E, D, A のみにセリフが存在し、C, B, S, SS には存在しない。
この場合、途切れている期間を表現するためにポジション指定を複数に分ける。

```yaml
  story_kaya:
    category: npc
    id: story_kaya
    positions:
      - x: 20
        y: 33
        flip: false
        min_rank: F
        max_rank: D  # F〜Dランクの間は出現
      - x: 20
        y: 33
        flip: false
        min_rank: A
        max_rank: A  # Aランクで再出現
```

## 3. キャラクターごとの配置場所の法則
- **基本ルール**: 休憩所の中で、それぞれのキャラクターの性格や状況に合った場所に配置する。
- **反抗勢力（カミラ・ガレス）**:
  ギルドに対する不信感を持っているため、目立つ場所には立たせない。
  「パブ（バー）の隅っこ」や「ギルド受付から最も遠い席・暗がり」などに配置する。
- **引退・変化後のNPC**:
  Aランクで「冒険者を辞めた」と語られるカヤやヘレナの場合、その情報はギルド職員や他のNPCから語られるため、本人は配置しない（＝テキスト通りに非表示にする）。
  モンスターやアイテムに変化したキャラクター（ユルやレインのSランクなど）は、変化後の姿（画像パス）でマップ上の片隅に配置する。

## 4. 今後の作業フロー（配置する時）
1. F〜SSランクまでの各階層の休憩所マップ（`.txt`）を作成する。
2. それぞれのマップに対応する `.yml`（村なら `village.yml`）を用意する。
3. AIに対して「`components/data/master/story_npc_placement_concept.txt` を読んで、完成した休憩所にストーリーNPCを配置して」と指示する。
4. AIが `npcs.yml` のセリフ設定とこのコンセプトを照らし合わせ、適切な `.yml` ファイルに `min_rank` / `max_rank` 付きで書き込む。
