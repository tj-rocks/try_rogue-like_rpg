## メインロジック変更後のテスト実行

以下のいずれかを変更した場合に実行:
- `systems/` 配下の `.py` ファイル
- `components/` 配下の `.py` ファイル
- `constants.py` / `dependencies.py` / `wordings.py`
- `main.py`

### 手順

1. **本ワークフローを読み直す**（特に「テスト失敗時の対応」を確認）
2. テストスイートを実行する
```bash
cd /Users/tj/Desktop/2DGame && TEST_MODE=1 ./tests/run_tests.sh
```

### テスト失敗時の対応

- テストを書き換えてパスさせることはしない
- まず失敗原因を確認する
  - テストが古い可能性を捨てない
  - 実装にバグがある可能性も確認する
- どちらが正しいか判断できない場合は、ユーザーに確認してから対応する

### 例外（テスト不要）

- `tools/` 配下のデバッグツール類（`ダンジョン系のデバッグ.py` 等）の修正は、自動テスト対象外のため実行不要
